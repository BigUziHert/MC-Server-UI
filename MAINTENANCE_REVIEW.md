## Boundaries retained

- Local owner access stays private; remote authentication, invitations, per-host sessions, permission checks, and same-window desktop connections remain intact.
- Recovery lists only direct managed instance folders and requires explicit confirmation. An intentionally removed server stays absent across restart until recovered.
- A transfer failure never authorizes partial promotion. Dependency conflicts, changed files, expired reviews, and invalid download integrity still stop installation.
- Tests use isolated files and controlled Minecraft process fixtures. They do not claim validation against a running production Minecraft world.
