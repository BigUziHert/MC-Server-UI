# Server software artwork

These original project logos identify compatible server software in MC Panel's
Versions page. They remain the artwork and trademarks of their respective owners;
their inclusion does not imply endorsement or affiliation. They are separate
from MC Panel's own branding and license. No artwork was generated or recolored.

The files are bundled so they remain available offline. `sources.json` records
the exact official download URL, retrieval date, file size, and SHA-256 for each
unmodified asset. Repository URLs are pinned to the revisions used when acquired.
The files are displayed with their original aspect ratios.
